# 🎒 Campus Lost & Found

A platform designed to help students quickly **report, discover, and recover lost items** on campus. Students can post lost or found items, search through listings, and connect with others to return belongings safely.

---

## ✨ Features

### 🔐 Student Authentication
- Student signup and login
- Secure user accounts
- Personalized item management

### 📌 Report Lost Items
- Create lost item reports
- Add item details such as name, description, and location
- Help others identify and return your belongings

### 📷 Report Found Items
- Upload images of found items
- Provide details about where and when the item was found
- Make it easier for owners to recognize their items

### 🔍 Search & Filter
- Browse all reported items
- Search by item name, category, or keywords
- Filter lost and found posts for faster discovery

### ✅ Claim Management
- Mark items as claimed after recovery
- Keep track of successfully returned items

### 🛠️ Admin Panel
- Manage user reports
- Review and moderate item posts
- Maintain a clean and reliable platform

---

## 🚀 Goal

To create a simple and efficient way for campus communities to reconnect students with their lost belongings.

---


Example:

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
